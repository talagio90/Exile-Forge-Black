# Exile Forge Black-Screen

A lightweight companion tool for **Exile Forge**, built specifically for botting-farm users who need to run the Black-Screen patch across many machines at once (50–200+), without the 1-license-per-HWID restriction of the main Exile Forge suite.

This tool applies **only** the Black-Screen patch (removes the black loading screen) — nothing else from the full Exile Forge feature set is included.

## License

Requires an active **Botting** tier license key. This tier is unlimited-machine (no HWID binding) and is a separate product from the main Exile Forge license — a regular Exile Forge key will **not** activate this tool, and vice versa.

Get a license key via our Discord: **https://discord.gg/77E3ffa547**

## Download

Grab the latest build from the [Releases](../../releases) page. No installation needed — just run the `.exe`.

## Usage

1. Launch `ExileForge.BlackScreen.exe`
2. Enter your Botting license key and activate
3. Select your game (Path of Exile 1 or 2) and browse to your install folder
4. Click **Apply**

Use **Recover** to restore the original game file at any time.

## Notes

- This is a self-contained, obfuscated build — some antivirus/SmartScreen engines may flag it as unknown/suspicious on first run (common false-positive for self-contained + protected .NET executables). The source is not open, but the tool only touches your local PoE installation files.
- Questions or issues — reach out on Discord.
